# Sync-Listening

Веб-приложение для совместного прослушивания музыки в реальном времени.

## Описание проекта

**Sync-Listening** — это распределённая система, позволяющая нескольким пользователям одновременно слушать музыку в общих комнатах.

Пользователи смогут создавать комнаты, приглашать друзей, добавлять музыкальные композиции в очередь и управлять воспроизведением. Все действия будут синхронизироваться между участниками в реальном времени.

## Используемые технологии

- **Python** — основной язык программирования.
- **FastAPI** — создание серверной части приложения.
- **python-socketio** — обмен событиями и синхронизация пользователей в реальном времени.
- **Memurai** — хранение данных и состояния комнат (совместим с Redis).
- **HTML, CSS, JavaScript** — клиентская часть приложения.
- **MP3** — формат музыкальных файлов.

## Архитектура проекта

Приложение состоит из нескольких основных частей:

1. **Клиентская часть** — пользовательский интерфейс для управления музыкой и комнатами.
2. **Серверная часть** — обработка запросов пользователей и управление воспроизведением.
3. **Memurai** — хранение информации о комнатах, пользователях, очередях и состоянии воспроизведения.
4. **Музыкальное хранилище** — хранение MP3-файлов на сервере.

## Основные возможности

### Реализовано
- Создана базовая серверная часть на FastAPI.
- Настроено подключение к Memurai.
- Добавлена базовая поддержка Socket.IO.

### Планируется
- Загрузка MP3-файлов.
- Создание и подключение к музыкальным комнатам.
- Совместное воспроизведение музыки.
- Синхронизация Play, Pause и Seek.
- Создание очереди воспроизведения.
- Голосование за пропуск композиции.
- Чат между участниками комнаты.

## Запуск проекта

### 1. Клонирование репозитория

```bash
git clone https://github.com/Igorek18/Sync-Listening.git
cd Sync-Listening
```

### 2. Создание виртуального окружения

```bash
python -m venv .venv
```

### 3. Активация виртуального окружения

Windows:

```bash
.venv\Scripts\activate
```

### 4. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 5. Запуск Memurai

Убедитесь, что служба Memurai запущена и доступна по адресу:

```text
localhost:6379
```

### 6. Запуск приложения

```bash
uvicorn main:app --reload
```

После запуска сервер будет доступен по адресу:

http://127.0.0.1:8000

#  Sync-Listening

Веб-приложение для совместного прослушивания музыки в реальном времени. Хост создает комнаты, пользователи подключаются к комнатам, пользователи могут добавлять треки в очередь и общаться друг с другом.

##  Возможности

- Создание комнат для прослушивания музыки.
- Синхронизация воспроизведения между пользователями.
- Управление музыкой: Play, Pause, Seek.
- Добавление треков в общую очередь.
- Голосование за пропуск трека.
- Чат между участниками комнаты.

##  Используемые технологии

- **React** — интерфейс приложения.
- **Node.js** — серверная часть.
- **Express** — обработка HTTP-запросов.
- **Socket.io** — обмен данными в реальном времени.
- **Redis** — хранение состояния комнат, очередей и голосов.
- **YouTube IFrame API** — воспроизведение музыки.

##  Как работает приложение

1. Пользователь создаёт комнату или подключается к существующей.
2. Клиент отправляет команды серверу через WebSocket.
3. Сервер обновляет состояние комнаты в Redis.
4. Изменения передаются всем участникам комнаты.
5. Все пользователи получают актуальное состояние воспроизведения.

##  Использование Redis

В проекте используются следующие структуры данных:

| Структура | Назначение |
|---|---|
| Hash | Хранение состояния комнаты |
| List | Хранение очереди треков |
| Set | Хранение участников и голосов |
| Pub/Sub | Передача событий между серверами |

##  Установка и запуск

### 1. Клонирование проекта

```bash
git clone https://github.com/Igorek18/sync-listening.git
cd sync-listening
```

### 2. Установка зависимостей

Для сервера:

```bash
cd server
npm install
```

Для клиента в отдельном терминале:

```bash
cd client
npm install
```

### 3. Запуск приложения

Запусти Redis и сервер:

```bash
npm run dev
```

Затем в папке клиента выполни:

```bash
npm run dev
```

Открой адрес, указанный в терминале.

*Команды запуска необходимо адаптировать под структуру проекта и настройки `package.json`.*
